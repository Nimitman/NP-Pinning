## Interactions (inferred from the flow)
- Back arrow → previous step (project selection).
- Row checkbox / "Select all" → toggles the row's selected state (lavender row bg + checked box; see m3.8 / m3.10).
- Pencil on "Price/sq.ft." or "Price" → **m3.9** Edit price sheet → save → **m3.10**.
- Warning triangle on a row → **m3.6** Report an issue sheet → send → **m3.7** → Done → **m3.8**.
- "+ Add missing configuration" → **m3.3** sheet → Add → **m3.4** → Back to pinning → **m3.5**.
- "Submit pinning request" with 0 configurations selected → **m3.2**.
- Start date field → date picker (not drawn). Duration cards → single select. "sq.ft." unit selector → unit menu (not drawn). Managed-by selector → manager or sub-broker picker (M4 flow).
