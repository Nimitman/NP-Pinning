## How we get here / exits
- Entry: click "Pin a project" (page header) or "+ Add new project pinning" (bottom CTA) on d1.2.
- City select → d1.4 (city dropdown). Locality select → d1.5. Typing in project → d1.6. Pick project → d1.7 (or d1.8 if already pinned).
- Close X / scrim click → back to d1.2.
- CTA disabled until a project is selected.
