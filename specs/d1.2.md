## CTA wrapper (12709:7574)
- 1200 x 82; bg #fff; border 1px #edebdf; radius **16px top-left/top-right only** (bottom corners square); padding 16; column gap 16.
- Primary button full width (1166x48): bg #4a16d9 (surface/brand), radius 12, height 48 (min/max 48), min-w 96, padding 12px 20px, centered label **+ Add new project pinning** — 14px/20px Medium 500, #fff, ls 0.1px (the "+" is part of the text; no icon).

## Interactions / where CTAs lead
- Back (←) → previous page (seller dashboard).
- "Pin a project" / "+ Add new project pinning" → d1.3 (select project dialog over this page).
- Card "Pin" → pin that project (goes to project summary step, cf. d1.7).
- Filter pills → dropdowns (cmp-recommendation-band.md D1/D2; city/locality panels).
- Carousel arrows → scroll cards; prev is disabled (opacity .4) on first page.
- Tabs filter the table; Export downloads; pagination pages the table.
- "Ending soon" row (4 days) shows warning-colored days.
