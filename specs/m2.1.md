# m2.1 — Mobile: Select a project to pin (default)

Figma frame 12788:228259 "2.1 · Select a project". **360 x 800**. Ref: `ref/m2.1.png`.
Purpose: step 1 of the mobile pinning flow — pick city, locality(ies) and a project. City/locality are prefilled from the seller's package; project is empty, so the CTA is disabled.
Entry: "Add new project pinning" on m1.1/m1.2. Interactions: city field → m2.2 (city sheet); locality field → m2.3 (locality sheet); typing in project search → m2.4 (results); back arrow → dashboard (m1.x). CTA disabled until a project is chosen (m2.5).
